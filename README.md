## 🚀 Featured Projects

### 🔬 Laparoscopy-Integrated SFDI/SSOP Imaging System
Real-time wide-field laparoscopic system for quantitative tissue optical property extraction in vivo. Enables intraoperative monitoring of chemophototherapy efficacy in ovarian cancer models.
`Python` `MATLAB` `SFDI` `Monte Carlo Simulation` `OpenCV` `LabVIEW`

### 🧠 Deep Learning for Optical Property Extraction
CNN and U-Net based solvers replacing iterative fitting in SFDI — achieving real-time optical property maps (μa, μs′) with high spatial resolution.
`PyTorch` `TensorFlow` `CNN` `U-Net` `Medical Imaging`

### 🧫 3D Cancer Spheroid Fluorescence Imaging
Mesoscopic fluorescence imaging pipeline for monitoring light-triggered drug release in 3D tumor spheroid models.
`Python` `Fluorescence Imaging` `Image Processing` `OpenCV`
